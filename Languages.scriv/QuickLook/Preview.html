        • String

          String Variables


          Reminder that you have a maximum of 26 string variables available to your entire program, starting with A$ and going through Z$.  There are no arrays of strings, but there is syntax that looks like arrays, for strings.


          You can DIM an array to have a particular amount of storage (defaulting to 72, which is also the length of the BASIC interpreter type-in keyboard entry buffer).

      • Interrupt Handling

        "Interrupts" are out-of-band / spontaneous changes to program control flow.  Like "On Error Goto" in applesoft and other BASICS.  When an interrupt happens, the current statement finishes executing, then a GOSUB happens to a previously registered line number.  Once the interrupt has been serviced, then you RETURN to resume the program where it left off.
