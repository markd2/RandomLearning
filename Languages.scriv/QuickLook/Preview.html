• Yay Languages

    Notes on programming languages, with a particular emphasis on the classic languages and implementations.


    Each language has its own folder which has the generic blurbage, and inside of that are documents for each specific implementation (e.g. VAX FORTRAN or Tektronix BASIC), and maybe subdocuments for better organization.

      • Environtment commands

        Environment Commands


        There is an "environment" of values that control different aspects of things. Some are legit BASIC commands, some are done via the device escape hatch of PRINT @1,2:3,4,5  where 1 is the device, 2 is the command to send to the device, and 3,4,5 (could be just one, could be more) are the parameters to that command.


        FUZZ

        Control how floating point numbers are compared.  Takes 1 or 2 parameters

      • Flow Comtrol

        GOTO - if you GO TO a line, then you're in single-step mode - it sets the program counter, and can STEP PROGRAM on the keyboard


        GO TO value OF 100,200,300,400 - use value to choose which line to go to


        GOSUB TO value OF 100,200,300 - same but with gosub
